# Raw input data (not tracked)

Place the raw volumetric water content (VWC) file (`SP03904_v2.csv`) downloaded from the EDI data package in this folder.

This repository does **not** track raw data files. After placing the files here, run the VWC workflow scripts in:
`scripts/volumetric_water_content/` (01 → 08).

If you encounter “file not found” errors, confirm the filenames and paths match what the scripts expect.
