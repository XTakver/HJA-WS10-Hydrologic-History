# Raw input data (not tracked)

Place the raw FTICR-MS data files (MAOM: `HJA_WS10_2023_MAOM_FTICR-MS.csv`; WEOM: `HJA_WS10_2023_WEOM_FTICR-MS.csv`) downloaded from the Zenodo data package in this folder.

This repository does **not** track raw data files. After placing the files here, run the mass_spectrometry workflow scripts in:
`scripts/mass_spectrometry/`.

If you encounter “file not found” errors, confirm the filenames and paths match what the scripts expect.
