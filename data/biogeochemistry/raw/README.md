# Raw input data (not tracked)

Place the raw Inorganic Nitrogen and Phosphorus file (`HJA_WS10_2023_Inorganic_Nitrogen_and_Phosphorus.csv`), Soil Carbon and Nitrogen Pools file (`HJA_WS10_2023_Soil_Carbon_and_Nitrogen_Pools.csv`), and Soil Ion and Nutrient file (`HJA_WS10_2023_Soil_Ion_and_Nutrients.csv`) downloaded from the Zenodo data package in this folder.

This repository does **not** track raw data files. After placing the files here, run the biogeochemistry workflow scripts in:
`scripts/biogeochemistry/`.

If you encounter “file not found” errors, confirm the filenames and paths match what the scripts expect.
