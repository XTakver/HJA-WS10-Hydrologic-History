# Raw input data (not tracked)

Place the raw vegetation files (`TP04101_v2.csv` and `TP04103_v2.csv`) downloaded from the EDI data package in this folder.

This repository does **not** track raw data files. After placing the files here, run the vegetation workflow scripts in:
`scripts/vegetation/` (01 → 04).

If you encounter “file not found” errors, confirm the filenames and paths match what the scripts expect.
