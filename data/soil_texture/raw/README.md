# Raw input data (not tracked)

Place the raw soil texture file (`SP03903_v1.csv`) downloaded from the EDI data package in this folder.

This repository does **not** track raw data files. After placing the files here, run the soil texture workflow scripts in:
`scripts/soil_texture/` (01 → 03).

If you encounter “file not found” errors, confirm the filenames and paths match what the scripts expect.
