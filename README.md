# HJA-WS10-Hydrologic-History

Reproducible analysis code for “Hydrologic History Drives Divergent Soil Organic Matter Trajectories Across Hillslopes”: soil-moisture time series, SOM fraction chemistry (FTICR-MS), vegetation, and soil properties across contrasting hillslope storage.

## Associated manuscript
- **Title:** Hydrologic History Drives Divergent Soil Organic Matter Trajectories Across Hillslopes 
- **Journal:** JGR Biogeosciences   
- **Authors:** X. Takver et al.

## Data availability
- **Soil Moisture, Texture, Aggregate Size Distribution, and Root Abundance (EDI):** https://doi.org/10.6073/pasta/189b29e9de90ec8ae79a0ca679c43e64  
- **Soil Biogeochemistry and FTICR-MS Organic Matter Chemistry (Zenodo):** https://doi.org/10.5281/zenodo.22920772 
- **Long-term vegetation data (EDI):** https://doi.org/10.6073/pasta/065e8bdaf36478d8e85ab0837d76bbe5  
- **Long-term precipitation data (EDI):** https://doi.org/10.6073/pasta/c30028e97bf7ec5be4fb72d08ab64bd2  

**Note:** This repository contains analysis code only. Data are archived at EDI and Zenodo (see [Getting the data](#getting-the-data)); FTICR-MS and biogeochemistry analyses were performed at EMSL under proposal 60921.

## Repository organization
- `data/`
  - `<dataset>/raw/` – raw data inputs (not tracked in git; see [Getting the data](#getting-the-data) for sources and folder placement)
  - `<dataset>/processed/` – intermediate/processed data generated by the `01_processing.R` scripts (not tracked in git; regenerated by running the pipeline)
- `output/` (not tracked in git; created by the provided scripts)
  - `figures/` – generated figures, organized by data stream
  - `statistics/` – generated statistical tables, organized by data stream
- `R`
  - `functions/` – shared helper functions sourced by analysis scripts (e.g., `initialize_font()`, `set_plot_theme()`, `paths_and_directories.R`)   
- `scripts/` – analysis scripts organized by data stream
- `assets/`
  - `fonts/roboto_condensed/` – bundled Roboto Condensed `.ttf` files used for reproducible figure rendering (see Reproducibility, below)

## How to run
### Quick start
1. Clone the repo
2. Restore dependencies (see below)
3. Run the workflow scripts for the desired data stream in numeric order (01 → 03)

Example:
- `scripts/<data_stream>/01_processing.R`
- `scripts/<data_stream>/02_statistics.R`
- `scripts/<data_stream>/03_figure_X.R`

### Reproducibility
- **R:** tested with R 4.6.1  
- Package versions are pinned with `renv` (see `renv.lock`). Run:
  - `renv::restore()`
- **Figure rendering:** This repository bundles static Roboto Condensed `.ttf` files in `assets/fonts/roboto_condensed/` to ensure cross-platform, reproducible figure rendering with plot theme and CairoPDF. Fonts are registered at runtime via `initialize_font()` in `R/functions/`. Font licensing information is included alongside the font files.

- Statistical tables: `output/statistics/`
